Projects

Some of the projects I have worked on in university, high school and on my own.

Desktop Security App

A personal project where I am building a desktop app that checks a computer for common security problems. It scans the system, watches important files for changes and keeps a log of what it finds.

Used: JavaScript, Electron

Learned: how common security issues show up on a real system

Cisco Network Setup

My final networking project, where I set up a network using Cisco routers and switches. I configured the devices, assigned IP addresses and tested that every device could communicate.

Used: Cisco routers and switches

Learned: how to plan, configure and troubleshoot a network

Hangman Game in Python

A hangman game I made in Python for my Intro to Programming course. The player guesses letters to find a hidden word before running out of tries.

Used: Python

Learned: loops, conditions and handling user input

Gravity and Roller Coasters

A high school physics project on how gravity affects a roller coaster. I looked at how height turns into speed as the coaster goes down hills and why it slows down going up.

Used: physics concepts of gravity and energy

Learned: how potential energy turns into kinetic energy

Trie Autocomplete in Python

A Standard Trie I built in Python for my Data Structures and Algorithms course. You type the start of a word and it returns every stored word that begins with it.

Used: Python

Learned: how tree structures make prefix searches fast
